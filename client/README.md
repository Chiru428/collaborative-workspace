# Client

Next.js front end for the collaborative workspace. See the [root README](../README.md) for setup, configuration and scripts.

```bash
cp .env.example .env.local   # set NEXT_PUBLIC_API_URL
npm install
npm run dev                 # http://localhost:3000
```

Note: this project uses a recent Next.js with breaking changes; see `AGENTS.md` and `node_modules/next/dist/docs/` before changing framework-level code.
